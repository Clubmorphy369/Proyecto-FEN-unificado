# ♟️ ChessSuite - Herramienta todo en uno para ajedrez

## 🚀 Funcionalidades

- **Extracción automática de FEN**: Sube imágenes o PDFs y obtén el FEN de cada tablero.
- **Recorte manual**: Edita y recorta tableros con precisión (arrastre y redimensionamiento).
- **Galería de recortes**: Guarda, asigna turno (blancas/negras) y organiza tus tableros.
- **Generación de PDF**: Crea PDFs con ejercicios en formato A4 (6 tableros por página).
- **Exportación a Lichess**: Descarga archivos PGN listos para importar en Lichess.

## 🛠️ Tecnologías

- **Backend**: Flask (Python), OpenCV, pdf2image, PyPDF2
- **Frontend**: HTML, CSS, JavaScript (puro, sin frameworks)
- **Despliegue**: Docker + Render
